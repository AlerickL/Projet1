Le dossier `doc/out/des/` contient tous les documents de *design* que vous devez produire pour ce projet. 

Le terme *design* fait référence à la phase de conception du **logiciel**. Ces documents peuvent être de différentes natures :
- planification logicielle
- architecture logicielle
- maquettes des interfaces graphiques 
- diagrammes de classes UML, qui représentent uniquement le modèle et jamais l'interface graphique
- spécifications des composants
- scénarios d'utilisation

Deux documents vous sont fournis ici et sont à compléter : `maquettes.md` assemble les maquettes, et `uml_modele.md` assemble les diagrammes de classes UML.

Les diagrammes et les maquettes sont des fichiers image déposés dans le dossier `doc/out/assets/`, puis insérés dans ces deux documents. Le format PNG est recommandé, et les autres formats d'image sont acceptés. Si un code source ou un fichier de travail a servi à les produire, il va dans le dossier `doc/out/work/`.

La version initiale de chaque diagramme et de chaque maquette, celle d'avant la programmation, est conservée dans `doc/out/assets/` à côté de la version finale. Les deux versions apparaissent dans ces documents. Le rapport final demande d'expliquer les écarts entre cette version initiale et le logiciel remis.

Il est essentiel de suivre les directives du projet pour connaître les documents obligatoires à produire et leur format.

Toute autre image utilisée par ces documents est aussi déposée dans le dossier `doc/out/assets/`.
