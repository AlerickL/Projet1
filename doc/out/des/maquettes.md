# Maquettes de l'interface graphique

Ce document assemble toutes les maquettes de l'interface graphique de votre logiciel. Consultez le guide [Le maquettage d'une interface graphique](../../in/guides/maquettage_interface_graphique.md) avant de commencer.

Les maquettes sont des fichiers image déposés dans le dossier `doc/out/assets/`. Le format PNG est recommandé. Chaque image est insérée ici, accompagnée de quelques mots d'explication. Une image s'insère ainsi :

```markdown
![Vue d'ensemble, version initiale](../assets/maquette_vue_ensemble_initiale.png)
```

Remplacez le contenu des sections par le vôtre, puis retirez les consignes en italique.

## Version initiale

*Insérez ici les maquettes produites avant le début de la programmation. Elles ne doivent pas être parfaites. Une fois la programmation commencée, ne les modifiez plus : le rapport final demande d'expliquer les écarts entre cette version et le logiciel remis.*

### Vue d'ensemble

*Présentez la fenêtre principale et la disposition de ses quatre sections : sélection de la courbe, transformation canonique, exploration de la méthode numérique et graphique.*

### Panneaux

*Ajoutez une maquette par panneau lorsque la vue d'ensemble ne suffit pas à en montrer le détail.*

## Version finale

*Insérez ici les maquettes mises à jour à la fin du projet, si l'interface a changé en cours de route. Si elle n'a pas changé, indiquez-le simplement.*
