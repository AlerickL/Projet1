Le dossier `doc/out/work/` contient tous les documents de travail personnels que vous avez produits pour ce projet. 

C'est ici que vous insérez vos documents de travail. Par exemple : 
- vous utilisez le logiciel Microsoft Excel pour faire quelques calculs, vous mettez ce fichier ici;
- vous utilisez Photoshop pour produire une image, vous mettez votre fichier de travail ici;
- vous utilisez PlantUML en ligne pour produire un diagramme, vous mettez votre script ici;
- etc.

C'est aussi ici que vont le code source et les fichiers de travail des diagrammes et des maquettes dont l'image est déposée dans `doc/out/assets/`. Ils doivent permettre de reproduire ces images.

Ce dossier est optionnel. Si vous n'utilisez aucun document de travail, par exemple si vos diagrammes sont dessinés à la main puis numérisés, il restera vide.
