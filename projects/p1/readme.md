### Dans Visual Studio Code

1. Ouvrir le dossier `sf3` avec *Fichier > Ouvrir le dossier*. C'est la racine : tous les fichiers de démarrage s'y trouvent.
2. Choisir l'interpréteur Python du cours : `Ctrl+Shift+P`, puis *Python: Select Interpreter*.
3. Ouvrir le fichier de démarrage voulu, puis cliquer sur *Run Python File* (▷), en haut à droite de l'éditeur.

| Fichier de démarrage | Ce qu'il lance |
| :--- | :--- |
| `p0_main.py` | le projet 0 |
| `p1_main.py` | le projet 1 |
| `learning_qpainter.py` | le guide interactif sur QPainter |
| `learning_pyqtgraph.py` | le guide interactif sur PyQtGraph |
